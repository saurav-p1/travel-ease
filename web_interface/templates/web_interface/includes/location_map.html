{% comment %} Reusable live location map. Drop this into any detail page that has a single point of interest with coordinates. It shows that point on a map, tracks the visitor's own GPS position in real time (via the browser's Geolocation API), draws a line between the two, and keeps a live "as the crow flies" distance updated. No API key is strictly required -- map tiles come from CARTO's free basemap tier (OpenStreetMap data, CARTO-hosted rendering; see CARTO_API_KEY below) and geolocation comes straight from the browser, so this keeps working as more destinations/restaurants (or any future point-of-interest type) get added with nothing to configure per-item. Without a CARTO_API_KEY, tiles still load and the map still works, just watermarked with "API KEY REQUIRED" (CARTO's own policy as of Aug 2026) -- see the CARTO_API_KEY comment further down for how to remove that. Required context: dest_lat -- latitude of the place (Decimal/float/int) dest_lng -- longitude of the place dest_name -- display name of the place map_id -- short unique slug for this page, e.g. "destination" or "restaurant" (lets more than one map safely exist across the site without id clashes) Optional context: pin_color -- hex color for the destination pin, defaults to the site's primary blue.
